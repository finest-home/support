# Finest support

Report problems and ideas for the [Finest Home](https://app.finest.rs) app and the
[Finest integration for Home Assistant](https://github.com/finest-home/integration) here,
in one place, whichever part you think is at fault.

- **Something doesn't work** or **an idea**: [open an issue](https://github.com/finest-home/support/issues/new/choose).
- **Questions about setup**: most answers are in the [setup guide](https://docs.finest.rs).
- **Account, subscription or payment**: email [support@finest.rs](mailto:support@finest.rs). Issues are public.
- **Security issues**: report them privately, see [SECURITY.md](SECURITY.md).

Issues here are public. Never post tokens, passwords, connection codes, your home's address or
anyone's name.

## How issues are handled

New issues are labelled `triage`. We add the part (`app`, `integration`), and ask for details
with `needs-info` when we can't reproduce something. An issue is closed when the fix is in a
released version; `in-next-release` means it's fixed and waiting for that release.

## Code

The source is in [finest-home/integration](https://github.com/finest-home/integration)
(the integration) and the app's repository. Pull requests go to the repository they change.
