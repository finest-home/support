# Security

If you think you've found a security issue in the Finest Home app, the Finest integration or
Finest's servers, please don't open a public issue. Email
[security@finest.rs](mailto:security@finest.rs) with the steps to reproduce and the versions
involved. We confirm receipt within three business days.

What's in scope and what we ask of you: [app.finest.rs/security](https://app.finest.rs/security).
